Sluggies-dat-tools

Export Mario Super Sluggers models and icons, edit them in Blender, and patch your changes back into the game files.

Test release {{RELEASE_NAME}}
Windows tools Blender add-on
  1. Bring your files
    Extract your own US-region dt_na.dat and main.dol into 1_Input.
  2. Export and edit
    Run StartTools.bat, export the models, and edit .sluggies files with the Blender add-on.
  3. Patch and play
    Patch your edits into 3_Output_Dat, then run the unpacked game in Dolphin.

Texture requirement: install Wiimms SZS Tools and make sure wimgt is on PATH. Game files are not included.
