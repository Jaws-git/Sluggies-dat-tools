Mario Super Sluggers — Player Data Structures in main.dol

Three contiguous tables in sec11 (0x806233C0–0x80639D00) hold all static per-character metadata. The most important for icon routing is the color-wheel attribute table. Virtual addresses shown; all values are big-endian. File-absolute offsets from the start of main.dol are noted in brackets: [0x...].

Color-Wheel Record  ×101  (8 bytes each)
+0x00 species_id  u8 — species / physical-type enum (0x00 solo, 0x0B Yoshi, 0x0C team-NPC-C, 0x0D team-NPC-D, …)
+0x01 captain_id  u8 — char ID of the species captain; equals char_id for captains and solo chars
+0x02 model_id  u8 — shared model/sprite index for this appearance; same value across all chars that share a model
+0x03 is_captain  u8 — 0x01 = captain or solo char; 0x00 = variant
+0x04 flag_b4  u8 — unknown flag; 0x01 for some variants, otherwise 0x00
+0x05 variant_index  u8 — zero-based position within species group (0 = captain, 1 = first variant, …)
Icon routing fields (patching targets for phase 5)
+0x06 icon_valid  u8 — 0x01 = character has a valid icon entry; 0x00 = no valid icon, draws Pink Yoshi fallback (page 0x8B cell 0x49).
All unused chars 0x59–0x5E are 0x00 here.
+0x07 icon_slot  u8 — per-species icon slot index, active when icon_valid == 1. Used to look up (front_page, front_cell, side_page, side_cell) in the per-species icon table (location not yet confirmed).
All unused chars 0x59–0x5E are 0x00 here.
examples Green Yoshi 0x06: 0B 06 06 01 01 00 01 03 — icon_valid=1 slot=3
Pink Yoshi  0x46: 0B 06 06 00 00 05 01 08 — icon_valid=1 slot=8
Unused Yoshi 0x47: 0B 06 06 00 00 06 00 05 — icon_valid=0 ← fallback
Unused char  0x59: 0D 59 2A 01 00 00 00 00 — icon_valid=0 ← fallback
Captain ID List 0x80631878  [0x0062D978] · 43 bytes + padding
+0x00 linear array of u8 captain char IDs — one entry per species / unique solo
entries 00 01 02 … 14 15 18 1B 1C 21 25–29 30 36–3A 3E–41 4D 59 (43 entries, null-terminated)
note 0x4D = captain of species 0x0C (team-NPC-C). 0x59 = captain of species 0x0D (team-NPC-D, the unused chars). These are the last two real entries before the null padding.
